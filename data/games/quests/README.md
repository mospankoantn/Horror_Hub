# Формат текстового квесту

Кожен квест — один JSON-файл у цій папці. Його читає рушій `js/game-room/games/quest.js`, тож коду писати не треба. Щоб квест з'явився в Ігровій кімнаті, додайте запис у `data/games.json` з `"engine": "quest"` і `"data": "data/games/quests/<файл>.json"`.

```json
{
  "id": "cinema-basement",
  "title": "Підвал під сценою",
  "start": "start",
  "fear": { "limit": 7, "scene": "fear_ending", "label": "Страх" },
  "scenes": {
    "start": {
      "text": "Текст сцени. \n\n — новий абзац.",
      "choices": [
        { "text": "Взяти ключ", "next": "take_key", "addItem": "ключ" },
        { "text": "Відчинити двері", "next": "exit", "requireItem": "ключ", "removeItem": "ключ" },
        { "text": "Покликати когось", "next": "call", "fear": 2 }
      ]
    },
    "exit": { "text": "Двері відчиняються…", "ending": "ВИ ВИБРАЛИСЯ.", "good": true },
    "fear_ending": { "text": "Страх перемагає…", "ending": "ВИ НЕ ВИТРИМАЛИ ТИШУ.", "bad": true }
  }
}
```

Поля сцени:
- `text` — текст, що друкується посимвольно (Пробіл або Enter показує його одразу).
- `choices` — до 9 варіантів (клавіші 1–9). Поля варіанта:
  - `next` — id наступної сцени;
  - `fear` — скільки страху додає;
  - `addItem` / `removeItem` — предмет в інвентарі;
  - `requireItem` — без цього предмета варіант недоступний;
  - `ignoreFear` — не переводить у фінал страху.
- `ending` — текст фіналу. Сцена з цим полем стає фіналом і рахується в колекції «Знайдено X з N». `good` чи `bad` задає колір і звук.

`fear.limit` — поріг страху: щойно він досягнутий, гра переходить у сцену `fear.scene`.

Id сцен — лише латиниця, цифри, `_` і `-`, до 40 символів. Сервер приймає в прогрес тільки id сцен, які в цьому файлі є фіналами.
